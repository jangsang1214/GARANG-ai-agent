# GARANG Anonymous External Validation Sprint v1

Status: IN PROGRESS
Start: 2026-09-22
Owners: Growth Business / Product / AI Data / Command Center

## Objective
Validate whether a person who has never seen GARANG can understand and act on the current Golden Path without founder explanation, then begin measuring whether GARANG's recommendation loop produces retained value over time.

## Constraints
- No friend/family/acquaintance testing.
- Do not recruit from a GARANG-branded account.
- Organic/free acquisition first; no paid ads in the first batch.
- Korean users and English-capable international users are both valid.
- Freeze new feature scope during the first evidence batch except verified P0/P1 fixes.
- Test the current product, not a founder-guided demo.

## Golden Path under test
signup/onboarding
→ first record
→ Coach interpretation
→ understand next action
→ plan
→ execution intent
→ Progress / accumulated-value understanding

## First batch
Target: 10–20 unknown users.

For each participant capture only what is needed to classify the journey:
1. reached signup
2. completed onboarding
3. created first record
4. saw Coach interpretation
5. could state the next action in their own words
6. created or understood a plan
7. expressed concrete execution intent
8. understood why Progress / accumulated history matters
9. primary confusion or abandonment point
10. whether they would return without being reminded

Do not coach the participant through the flow. If they ask what to do, record that as comprehension evidence before answering.

## Funnel classification
- Acquisition failure: never starts.
- Activation failure: starts but does not reach first meaningful record/Coach value.
- Comprehension failure: reaches a surface but cannot explain what GARANG wants them to do next.
- Action failure: understands but does not intend/attempt the next action.
- Retention/value failure: completes the loop but sees no reason to return.
- Reliability failure: product/runtime issue prevents otherwise-valid progress.

## Longitudinal follow-up
At 2 / 4 / 8 weeks, measure attributable Intelligence Episodes:
recommendation shown
→ accepted / edited / rejected / ignored
→ execution evidence
→ outcome evidence
→ later recommendation behavior

Primary measures:
- activation completion rate
- first-record completion
- Coach-to-next-action comprehension
- recommendation acceptance/edit/reject distribution
- execution rate after recommendation
- outcome-attribution coverage
- return/continued-use evidence
- repeated failure themes

## Decision rule
Do not add a feature because one participant asks for it.
Promote a change only when it is supported by repeated evidence, a material funnel drop, or a verified critical failure.

After the first 10–20 users:
- keep: flows with high comprehension + action conversion
- fix: repeated high-impact drop-offs
- simplify: confusing surfaces that do not add retained value
- stop/defer: requests not connected to the Golden Path or measured retention
- deepen intelligence only when episode evidence shows a clear opportunity

## Founder operating rule
The next product decision must come from external evidence, not from the existence of another buildable feature.
